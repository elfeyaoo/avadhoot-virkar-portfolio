# Avadhoot Virkar — Portfolio

A modern, animated personal portfolio built with:

- Next.js
- React
- TypeScript
- Framer Motion
- Lucide React
- Custom CSS
- Vercel-ready deployment

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Add your resume

Put your latest resume at:

```text
public/resume.pdf
```

## Customize

The main portfolio content is in:

```text
app/page.tsx
```

Global styling is in:

```text
app/globals.css
```

Update:
- Project descriptions
- GitHub links
- LinkedIn link
- Skills
- About section
- Resume
- Project screenshots

## Deploy

Push the repository to GitHub and import it into Vercel.

Recommended production domain:

`avadhootvirkar.com`

if available.
