# Avadhoot Virkar — Portfolio

Modern Next.js portfolio tailored to the Data Analyst / BI Analyst / Data Analytics resume.

## Stack
Next.js 15 · React · TypeScript · Framer Motion · Lucide React

## Run locally
```bash
npm install
npm run dev
```

For a production check:
```bash
npm run build
npm start
```

## Resume
Place the supplied/latest resume PDF at:
`public/resume.pdf`

The current site content is based on the provided Data Analyst / BI Analyst resume. Replace any placeholder links (especially LinkedIn) with the actual profile URL before publishing.

## Deployment
Push to GitHub, import the repository into Vercel, and use the default Next.js settings:
- Framework: Next.js
- Root Directory: `./`
- Build Command: `npm run build`
- Install Command: `npm install`
